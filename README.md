# Naman Jiwrajka — Portfolio

A responsive student portfolio for Naman Jiwrajka, B.Tech CSE (AI), Geeta University, NextWave.

## Files
- `index.html` — page structure/content
- `style.css` — design and responsive layout
- `script.js` — mobile navigation

## Before publishing
Open `index.html` and replace:
1. `https://github.com/` with your actual GitHub profile URL.
2. `your-email@example.com` with your actual email address.

## Deploy with GitHub Pages
1. Create a new GitHub repository, e.g. `naman-portfolio`.
2. Upload `index.html`, `style.css`, `script.js`, and optionally `README.md`.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then **Save**.
6. Wait a few minutes and open the generated Pages URL.
7. Test the URL in an incognito window and on your phone before submitting it.
